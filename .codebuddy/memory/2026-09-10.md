# 2026-09-10

## AI 面板打开 / 切会话“从头滚到尾”（已修）
- 根因：消息 effect 用 `scrollIntoView({ behavior: 'smooth' })`，打开面板（`leftActivity==='ai'`）、切换会话、载入历史时也走 smooth → 视觉上从消息顶部一路滚到底部。
- 修复：新增 `aiInstantScrollRef` 标记——①刚进入 AI 面板时置位；②切换会话的 `useLayoutEffect`（瞬时 `scrollTop`）也置位；滚动 effect 读到标记则直接 `scrollTop = scrollHeight`（瞬时）并清标记。**新消息追加 / 生成中仍保留 smooth**。
- 验证：`npx tsc --noEmit` 通过。

## AI 面板「清除全部对话」（新增）
- 原 Trash2 按钮只清空当前对话（清 messages 保留会话）；用户要“清除整个”。
- 现在两个按钮：`Eraser`=清空当前对话（原 `clearAiConversation`），`Trash2`=**清除全部对话**（新 `clearAllAiConversations`，`requestConfirm` 危险确认）。
- 实现：后端没有批量删除命令，前端逐个 `deleteAiConversation(id)`（会话量小，可接受）；全部删完后本地 `setAiWorkspace` 重置为一个 `createAiConversationState()` 空白会话——激活会话变化会触发已有的 600ms 防抖 `saveAiConversation`，空白会话自动落库。
- 按钮 disabled 条件：没有任何会话含消息时禁用。
