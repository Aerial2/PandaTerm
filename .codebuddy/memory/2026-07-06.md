## 修复：连接管理窗口新建/删除后列表不刷新
- 文件：`apps/desktop-ui/src/ConnectionWindow.tsx`
- 根因：「连接管理」(`connection-panel`) 与「新建连接」(`connection-create`) 是两个独立 Tauri Webview 窗口，各自持有 `sessions` 状态。新建窗口保存后只更新自身状态并关闭，管理窗口无感知。
- 修复：保存/删除成功后全局 `emit('sessions-changed')`；每个 `ConnectionWindow` 实例监听该事件并 `refreshSessions()`（含监听器清理）。

## 修复：多屏下连接/新建窗口定位跑到主屏且不在触发窗口中央
- 文件：`apps/desktop-ui/src/api.ts` 与 `apps/desktop-ui/src/ConnectionWindow.tsx`
- 根因：`openConnectionWindow` 用 `center: true`（始终主屏居中）；`ConnectionWindow` 挂载时又调用 `win.center()` 二次拉回主屏。
- 修复：`api.ts` 改为读取触发窗口（`getCurrentWebviewWindow`）的 `scaleFactor/outerPosition/outerSize`，换算逻辑坐标后让新窗口在触发窗口中央；失败才 fallback 到 `center`。`ConnectionWindow.tsx` 移除 `win.center()`，保留创建时位置。

## 修复：编辑连接后保存出现两条重复记录
- 文件：`apps/desktop-ui/src/ConnectionWindow.tsx`
- 根因：`saveAndConnectConnection` 始终 `crypto.randomUUID()` 生成新 id，编辑流程（`loadSessionToForm`）只回填表单却不记录原 id，导致后端按新 id `upsert` 成新增项。
- 修复：新增 `editingId` 状态；`loadSessionToForm` 记录被编辑 session 的 id；保存时复用该 id，并保留原 `group/tags/last_connected_at/reconnect`，仅更新可编辑字段；保存/取消后重置 `editingId`。编辑时按钮文案为「保存」且不自动连接，新建时仍为「保存并连接」。
